# AsmFoundation/.github

The AsmFoundation organization's special repository. GitHub reads two
things from it:

- **[`profile/README.md`](profile/README.md)** is the page shown at
  <https://github.com/AsmFoundation>. Its banner has a light and a dark
  variant in [`profile/assets/`](profile/assets):
  - `panel.png` is the transparent original, for light themes.
  - `panel-dark.png` is the same panel on a white rounded card. Its
    dark-teal labels would be nearly invisible on GitHub's dark background
    otherwise.
- **[`SECURITY.md`](SECURITY.md)** is the default security policy. GitHub
  applies it to every repository in the organization that has no policy of
  its own.
